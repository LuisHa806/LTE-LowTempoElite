# LTE — Low Tempo Elite

Official clan landing page for LTE, built as a static site. The original LTE logo is kept as the supplied PNG and displayed in a gold 3D-style frame.

## GitHub Pages

A GitHub Actions workflow is included in `.github/workflows/pages.yml`. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions** if GitHub has not enabled it automatically. New commits to `main` then redeploy the website.

The site is plain HTML, CSS, and JavaScript. There is no build step or dependency installation.
